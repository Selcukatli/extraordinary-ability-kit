# Volatile Facts

Every number in this file has a shelf life. Fees change, approval rates move each fiscal
year, and processing times drift. **This is the only file in the skill that carries such
numbers** — the rest of the reference is written to stay true as they change.

> [!warning] How an agent must use this file
> 1. Quote a figure ONLY together with its verification date: *"as of February 2026,
>    …"* — never as a bare present-tense fact.
> 2. If `last-verified` is more than **six months** before today, say so explicitly and
>    tell the user to confirm against the primary source before relying on it.
> 3. For anything the user will pay or file on, send them to the primary source:
>    - Fees and processing times — <https://www.uscis.gov/forms/filing-fees> and the
>      USCIS processing-times tool
>    - Visa bulletin / priority dates — <https://travel.state.gov> visa bulletin

## Premium processing

*Snapshot date: February 2026. A fee increase was scheduled for March 1, 2026, which has
since passed — treat the post-increase column as current but confirm before filing.*

| Form | Classification | Fee before 2026-03-01 | Fee from 2026-03-01 | Adjudication window |
|---|---|---|---|---|
| I-129 | O-1A | $2,805 | $2,965 | 15 business days |
| I-140 | EB-1A | $2,805 | $2,965 | 15 business days |
| I-140 | EB-1C, EB-2 NIW | $2,805 | $2,965 | 45 business days |

Requested on **Form I-907**. The clock starts when USCIS receives the I-907, and an RFE
stops it — it restarts on receipt of the response.

## RFE rates

*Snapshot date: February 2026.*

- EB-1A RFEs issued in roughly **40–50%** of filings.
- Effective RFE responses still convert at roughly **60%** approval.
- RFEs have grown both more frequent and broader in scope.

**Plan for an RFE rather than treating it as failure.** A well-documented petition that
draws an RFE and answers it well is a normal path to approval.

## Statutory windows that do not change

These are regulatory, not administrative, and belong here only so agents stop looking
for them among the volatile numbers:

- **240-day rule** — a beneficiary whose timely-filed O-1 extension is pending may
  continue working for the same employer for up to 240 days past I-94 expiry.
- **O-1 validity** — up to 3 years initially; extensions in 1-year increments.
